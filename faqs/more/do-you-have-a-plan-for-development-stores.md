# Do you have a plan for development stores?

If you have a store that will never see customer traffic, such as a sandbox or staging store used only for building and testing, we can help with that. :) Locksmith doesn't have a separate plan for these, but we do grant super-extended trial periods for development stores.

Write in to [team@uselocksmith.com](mailto:team@uselocksmith.com), let us know which store it is (its `.myshopify.com` address), and that it'll stay a development store, and we'll set it up.

For a store that will go live, the usual free trial applies. If you need more time to finish building before launch, write in and we'll talk it through.
